# 💻 Projeto de Estudos em Java

Este repositório contém exercícios e exemplos básicos escritos em Java, desenvolvidos como parte do meu aprendizado da linguagem. Cada arquivo aborda um tema específico para praticar conceitos fundamentais da programação em Java.

---

## 📁 Arquivos do projeto

| Arquivo                 | Descrição                                      |
|-------------------------|-----------------------------------------------|
| `Main.java`             | Estrutura principal de um programa em Java.   |
| `Condicional.java`      | Exemplo de uso de estruturas condicionais.    |
| `Loop.java`             | Demonstração de laços de repetição (`while`, `for`). |
| `OutroLoop.java`        | Mais exemplos de loops com variações.         |
| `Leitura.java`          | Uso do `Scanner` para entrada de dados.       |
| `DesafioTemperatura.java` | Conversor de temperatura - desafio prático.  |
| `DadosBancarios.java`   | Simulação simples de um menu bancário.        |

---

## 🛠️ Tecnologias Utilizadas

- Java 17 (ou a versão que estiver usando)
- IntelliJ IDEA
